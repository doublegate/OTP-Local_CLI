# S-AUTH-9.2: Linux PAM integration module for sudo and SSH

Status: Completed; tasks verified by test suite.

## Goal and Scope

Implement a native Linux Pluggable Authentication Module (`pam_otp_local.so`) written in C (with Python ctypes test harness) that interfaces with the local resident daemon via UNIX socket, providing instant TOTP 2FA verification for `sudo`, SSH, and system authentication stacks without external network dependencies.

Non-goals: Modifying host `/etc/pam.d/` configurations without explicit operator confirmation; plain-text password checking.

## Entry Conditions and Dependencies

Dependencies: S-AUTH-9.1 (Resident UNIX socket daemon and IPC protocol operational).

## Tasks

- [x] **T-AUTH-100:** Implement native C PAM module `pam/pam_otp_local.c` implementing `pam_sm_authenticate` and `pam_sm_setcred` with conversation prompt handling and strict fail-closed logic.
- [x] **T-AUTH-101:** Build `pam/Makefile` and automated build pipeline supporting GCC and Clang with hardening flags (`-fstack-protector-strong -D_FORTIFY_SOURCE=2 -fPIE`).
- [x] **T-AUTH-102:** Implement PAM configuration validator and dry-run CLI diagnostic tool `otp-local doctor --pam` in `src/authy_local/pam_check.py`.
- [x] **T-AUTH-103:** Build synthetic PAM conversation test harness in `tests/test_pam_integration.py` verifying successful verification, incorrect codes, timeouts, and daemon-offline fallback.

## Outputs

- PAM module source `pam/pam_otp_local.c` and build script `pam/Makefile`.
- Diagnostic tool `src/authy_local/pam_check.py`.
- Automated test suite `tests/test_pam_integration.py`.

## Validation and TDD

- Synthetic PAM test harness validating standard authentication transactions without root requirements.
- Fail-closed verification: daemon shutdown immediately causes PAM module to safely reject authentication without hanging.
