# S-AUTH-7.1: Windows DPAPI and Credential Manager backend

Status: Completed; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement the native Microsoft Windows storage backend in `src/authy_local/backends/dpapi.py` utilizing the Windows Data Protection API (`CryptProtectData` and `CryptUnprotectData`) and Windows Credential Manager (`CredWriteW` / `CredReadW`) via `ctypes` or `win32crypt`, providing hardware-backed master key derivation bound to the user profile or Windows Hello biometric container.

Non-goals: Modifying POSIX Keychain or TPM backends; running non-sandboxed Windows commands on Linux test hosts.

## Entry Conditions and Dependencies

Dependencies: Phase 0–6 completed; Windows platform capability definitions registered in doctor module.
