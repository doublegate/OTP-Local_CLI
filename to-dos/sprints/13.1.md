# S-AUTH-13.1: Freedesktop Secret Service D-Bus provider and session negotiation

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement the native Linux D-Bus Freedesktop Secret Service provider (`org.freedesktop.secrets`) in `src/authy_local/secret_service.py` to allow desktop applications to securely discover, unlock, and query OTP credentials through standard system calls.

Non-goals: Global keyring hijacking without explicit user opt-in or daemon activation.

## Entry Conditions and Dependencies

Dependencies: Universal async architecture; D-Bus runtime or mock socket harness.

## Tasks

- [ ] **T-AUTH-130:** Implement `SecretServiceProvider` D-Bus service exposing `org.freedesktop.Secret.Service` and `org.freedesktop.Secret.Collection` interfaces.
- [ ] **T-AUTH-131:** Implement Diffie-Hellman session negotiation (`dh-ietf1024-sha256-aes128-cbc-pkcs7`) and plain session handling.
- [ ] **T-AUTH-132:** Map OTP account items to `org.freedesktop.Secret.Item` with attributes (`xdg:schema`, `service`, `account`).
- [ ] **T-AUTH-133:** Build automated D-Bus protocol test suite in `tests/test_secret_service.py` verifying search, unlock, and retrieve flows.

## Outputs

- Secret service provider module `src/authy_local/secret_service.py`.
- Automated test suite `tests/test_secret_service.py`.

## Validation and TDD

- Synthetic D-Bus test harness verifying complete Secret Service API lifecycle.
- Interoperability tests with `secret-tool` command-line utility.
