# S-AUTH-8.2: FIDO2 interactive enrollment, touch presence, and TUI integration

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement interactive multi-token FIDO2 enrollment, physical touch presence prompts, and real-time Textual TUI visual indicators, supporting backup key registration and graceful touch-timeout handling.

Non-goals: Modifying external identity providers or remote WebAuthn servers.

## Entry Conditions and Dependencies

Dependencies: S-AUTH-8.1 (FIDO2 CTAP2.1 hardware core operational).

## Tasks

- [ ] **T-AUTH-092:** Implement multi-token enrollment architecture supporting primary and secondary backup hardware tokens with synchronized salt configurations.
- [ ] **T-AUTH-093:** Implement Textual TUI `Fido2TouchModal` featuring an interactive pulsing visual touch indicator and timeout countdown timer in `src/authy_local/tui.py`.
- [ ] **T-AUTH-094:** Integrate FIDO2 hardware backend selection into CLI `otp-local enroll --fido2` and TUI `AddOtpModal`.
- [ ] **T-AUTH-095:** Build automated UI and adversarial interaction tests in `tests/test_fido2_tui.py` validating modal popups, touch simulation, and device disconnects.

## Outputs

- Textual TUI touch prompt widgets in `src/authy_local/tui.py`.
- CLI enrollment extension in `src/authy_local/cli.py`.
- Automated test suite `tests/test_fido2_tui.py`.

## Validation and TDD

- Headless Textual pilot testing verifying touch prompt appearance and timeout handling.
- Verification of clean memory erasure of all cryptographic challenge buffers.
