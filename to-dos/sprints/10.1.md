# S-AUTH-10.1: Bitwarden and Vaultwarden CLI backend and session management

Status: Completed; tasks verified by test suite.

## Goal and Scope

Implement the native Bitwarden / Vaultwarden storage backend in `src/authy_local/backends/bitwarden.py` interfacing with the official `bw` command-line utility, supporting automated session unlocking (`bw unlock`), protected in-memory session token caching (`BW_SESSION`), and high-performance TOTP credential extraction.

Non-goals: Storing master passwords; transmitting credentials over third-party telemetry.

## Entry Conditions and Dependencies

Dependencies: Phase 0–9 completed; `bw` CLI binary detected on path or mockable via synthetic subprocess harness.
