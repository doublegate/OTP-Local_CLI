# S-AUTH-14.2: RFC 4226 HOTP counter-based engine and desync recovery

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement the RFC 4226 counter-based HOTP engine in `src/authy_local/hotp.py`, managing persistent counter storage, atomic advancement, lookahead verification windows, and counter resynchronization.

Non-goals: Unbounded lookahead windows that introduce brute-force vulnerabilities.

## Entry Conditions and Dependencies

Dependencies: S-AUTH-14.1 completed; atomic file write utilities.

## Tasks

- [ ] **T-AUTH-144:** Implement `HotpEngine` with atomic on-disk counter advancement and crash-consistent persistence.
- [ ] **T-AUTH-145:** Implement bounded lookahead resynchronization window (RFC 4226 Section 7.4) recovering desynchronized tokens.
- [ ] **T-AUTH-146:** Add CLI command `otp-local next <account>` and Textual TUI action `HOTP Advance` for manual counter increment.
- [ ] **T-AUTH-147:** Build automated concurrency, counter rollback prevention, and RFC 4226 test suite in `tests/test_hotp.py`.

## Outputs

- HOTP counter engine `src/authy_local/hotp.py`.
- Automated test suite `tests/test_hotp.py`.

## Validation and TDD

- RFC 4226 Appendix D golden test vectors passing across 10 sequential counter increments.
- Rollback prevention verification under simulated power-cut or SIGKILL signals.
