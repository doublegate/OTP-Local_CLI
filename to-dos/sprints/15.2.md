# S-AUTH-15.2: Decentralized sync transports (WebDAV, S3, conflict resolution)

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement non-blocking decentralized synchronization transports in `src/authy_local/sync.py` supporting WebDAV (Nextcloud / ownCloud) and S3-compatible object storage (MinIO / AWS S3) with etag-based conflict resolution.

Non-goals: Proprietary central server dependencies or unauthenticated cloud telemetry.

## Entry Conditions and Dependencies

Dependencies: S-AUTH-15.1 completed; async HTTP/S3 client adapter.

## Tasks

- [ ] **T-AUTH-154:** Implement `WebDavSyncClient` supporting digest and bearer authentication with conditional etag PUT/GET.
- [ ] **T-AUTH-155:** Implement `S3SyncClient` utilizing AWS SigV4 request signing for MinIO and AWS S3 buckets.
- [ ] **T-AUTH-156:** Implement deterministic three-way merge engine reconciling simultaneous local and remote vault changes.
- [ ] **T-AUTH-157:** Build automated mock sync server and network disruption test suite in `tests/test_sync.py`.

## Outputs

- Synchronization module `src/authy_local/sync.py`.
- Automated test suite `tests/test_sync.py`.

## Validation and TDD

- Mock WebDAV and S3 servers validating synchronization lifecycle and error handling.
