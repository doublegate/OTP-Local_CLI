# S-AUTH-16.1: Mobile authenticator ingestion (Aegis, 2FAS, Ente, Google Protobuf)

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement zero-knowledge ingestion of mobile authenticator export files in `src/authy_local/migration.py`, specifically Aegis encrypted JSON, 2FAS encrypted vaults, Ente Auth backups, and Google Authenticator protobuf QR payloads.

Non-goals: Mobile cloud scraping or bypassing user backup passphrases.

## Entry Conditions and Dependencies

Dependencies: Phase 15 completed; SCrypt, AES-GCM, and Protobuf decoding primitives.

## Tasks

- [ ] **T-AUTH-160:** Implement Aegis encrypted JSON decoder supporting SCrypt key derivation and AES-GCM vault decryption.
- [ ] **T-AUTH-161:** Implement 2FAS encrypted container reader and Ente Auth format parser.
- [ ] **T-AUTH-162:** Implement Google Authenticator `otpauth-migration://` URI scheme parser and protobuf batch unpacker.
- [ ] **T-AUTH-163:** Build automated fixture-based import test suite in `tests/test_migration_importers.py`.

## Outputs

- Mobile migration parsers in `src/authy_local/migration.py`.
- Automated test suite `tests/test_migration_importers.py`.

## Validation and TDD

- Golden fixture tests validating complete extraction across representative export files from each ecosystem.
- Error handling tests validating graceful rejection of wrong passwords or corrupted archives.
