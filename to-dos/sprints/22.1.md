# S-AUTH-22.1: FIDO2 Passkey software authenticator (resident keys, assertions)

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement a software FIDO2 / Passkey authenticator in `src/authy_local/passkeys.py` capable of generating discovering resident public-key credentials and responding to CTAP2.1 authenticator challenges.

Non-goals: Exporting private signature keys in unencrypted format.

## Entry Conditions and Dependencies

Dependencies: Phase 21 completed; Ed25519 and P-256 elliptic curve cryptography primitives.

## Tasks

- [ ] **T-AUTH-220:** Implement CTAP2.1 `authenticatorMakeCredential` generating resident public-key pairs.
- [ ] **T-AUTH-221:** Implement CTAP2.1 `authenticatorGetAssertion` generating signed assertion responses.
- [ ] **T-AUTH-222:** Implement encrypted resident credential storage with biometrics or master passphrase protection.
- [ ] **T-AUTH-223:** Build automated WebAuthn authenticator conformance test suite in `tests/test_passkeys.py`.

## Outputs

- Passkey authenticator engine `src/authy_local/passkeys.py`.
- Automated test suite `tests/test_passkeys.py`.

## Validation and TDD

- Passkey registration and assertion validation against standard FIDO2/WebAuthn test vectors.
- Private key non-exportability and cryptographic zeroization verification.
