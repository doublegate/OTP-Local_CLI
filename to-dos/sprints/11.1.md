# S-AUTH-11.1: Memory forensics hardening and core dump protection

Status: Complete; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement military-grade runtime memory security in `src/authy_local/security.py`, including locking sensitive memory pages into RAM using `mlock()` (preventing paging to unencrypted swap disks), excluding memory regions from crash dumps via `madvise(MADV_DONTDUMP)`, and enforcing deterministic buffer zeroization via `ctypes.memset` on sensitive bytearrays upon process termination or signal interruption.

Non-goals: Modifying kernel virtual memory subsystems; running privileged kernel modules.
