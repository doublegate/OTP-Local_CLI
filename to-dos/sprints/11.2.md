# S-AUTH-11.2: Autonomous security auditor v2, entropy analysis, and rotation engine

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement the Autonomous Security Auditor v2 in `src/authy_local/auditor.py`, featuring automated Shannon entropy calculations on enrolled Base32 secrets, RFC 6238 time drift diagnostics, an environment secret-leakage detector (`/proc/$PID/environ`, shell history, arguments), and an interactive secret rotation advisor.

Non-goals: Modifying user credentials without explicit confirmation; network reporting.

## Entry Conditions and Dependencies

Dependencies: S-AUTH-11.1 (Memory hardening operational).

## Tasks

- [ ] **T-AUTH-116:** Implement secret entropy analyzer calculating Shannon entropy, key length checks, and legacy SHA1 deprecation flags.
- [ ] **T-AUTH-117:** Implement host time drift and NTP skew detector calculating local clock deviation against RFC 6238 timing boundaries.
- [ ] **T-AUTH-118:** Implement environment leak scanner inspecting `/proc/$PID/environ`, command line arguments, and local shell history files for leaked secret keys.
- [ ] **T-AUTH-119:** Implement guided secret rotation assistant CLI command `otp-local audit --rotate` with interactive backend updates and test verification.

## Outputs

- Security auditor engine `src/authy_local/auditor.py`.
- Automated test suite `tests/test_auditor_v2.py`.
