# S-AUTH-7.2: Windows shell ecosystem, PowerShell/NuShell wrappers, and WSL2 interop

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement first-class Windows shell integrations for PowerShell (`Microsoft.PowerShell`), NuShell (`nu`), and Windows Terminal, alongside a bidirectional IPC bridge between WSL2 (Windows Subsystem for Linux) and the host Windows DPAPI storage backend via named pipes.

Non-goals: Modifying Fish or Zsh POSIX shell wrappers.

## Entry Conditions and Dependencies

Dependencies: S-AUTH-7.1 (Windows DPAPI backend operational).

## Tasks

- [ ] **T-AUTH-084:** Implement native PowerShell module and integration script `shell/otp-local.ps1` supporting interactive tab completions, pipeline input, and clipboard synchronization via `Set-Clipboard`.
- [ ] **T-AUTH-085:** Implement NuShell module and completions in `shell/otp-local.nu` supporting structured table output and fuzzy matching.
- [ ] **T-AUTH-086:** Implement WSL2 named pipe interop relay in `src/authy_local/wsl_bridge.py` allowing Linux guests to query host Windows DPAPI secrets securely.
- [ ] **T-AUTH-087:** Build automated synthetic test suites in `tests/test_windows_shells.py` and `tests/test_wsl_bridge.py`.

## Outputs

- Shell integration scripts `shell/otp-local.ps1` and `shell/otp-local.nu`.
- WSL2 bridge module `src/authy_local/wsl_bridge.py`.
- Automated test suites passing 100%.

## Validation and TDD

- Synthetic shell invocation and argument parsing verification.
- Mocked named pipe client/server handshakes verifying UID and session isolation.
