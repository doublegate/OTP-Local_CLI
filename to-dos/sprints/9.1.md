# S-AUTH-9.1: Resident UNIX socket daemon and shared-memory IPC ring buffer

Status: Completed; tasks verified by test suite.

## Goal and Scope

Implement a resident background daemon (`otp-local daemon`) maintaining an in-memory decrypted token cache in locked RAM, exposing a low-latency UNIX domain socket at `/run/user/$UID/otp-local.sock` with binary CBOR serialization, paired with a POSIX shared-memory circular ring buffer (`/dev/shm/otp-local-$UID`) achieving sub-millisecond (<0.1ms) code generation.

Non-goals: Network-exposed TCP sockets; root daemon execution.

## Entry Conditions and Dependencies

Dependencies: Phase 0–8 completed; POSIX shared memory and UNIX domain sockets supported on host.

## Tasks

- [x] **T-AUTH-096:** Implement resident daemon server in `src/authy_local/daemon.py` with standard lifecycle controls (`start`, `stop`, `status`, `reload`), systemd user service generation, and PID file management.
- [x] **T-AUTH-097:** Implement high-speed IPC protocol in `src/authy_local/ipc.py` communicating over `/run/user/$UID/otp-local.sock` with binary CBOR serialization and strict `SO_PEERCRED` caller UID enforcement.
- [x] **T-AUTH-098:** Implement zero-copy POSIX shared-memory ring buffer in `src/authy_local/shm.py` with atomic spinlock synchronization for sub-0.1ms retrieval.
- [x] **T-AUTH-099:** Build automated daemon lifecycle and IPC concurrency test suite in `tests/test_daemon_ipc.py`.
