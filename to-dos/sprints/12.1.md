# S-AUTH-12.1: Universal async engine and fast streaming JSON-RPC / CBOR protocol

Status: Complete; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement the core non-blocking asynchronous architecture (`asyncio`) in `src/authy_local/async_core.py`, upgrading backend queries, vault synchronizations, and TUI worker threads to native coroutines, paired with a universal streaming JSON-RPC / CBOR socket protocol.

Non-goals: Breaking existing synchronous CLI command outputs or return code conventions.

## Entry Conditions and Dependencies

Dependencies: Phase 0–11 completed; Python 3.10+ async runtime.

- [x] **T-AUTH-122:** Implement universal JSON-RPC 2.0 / CBOR streaming protocol for daemon and client communication with bi-directional notifications.
- [x] **T-AUTH-123:** Build automated concurrency and async stress test suite in `tests/test_async_core.py`.
