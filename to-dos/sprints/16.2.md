# S-AUTH-16.2: Password manager interoperability (1Password, Bitwarden, KeePassXC)

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement cross-vault interoperability with major desktop password managers in `src/authy_local/migration.py`, parsing 1Password 1PUX zip archives, Bitwarden encrypted/unencrypted JSON exports, and KeePassXC KDBX/CSV exports.

Non-goals: Storing master passwords or cloud synchronization credentials in plaintext.

## Entry Conditions and Dependencies

Dependencies: S-AUTH-16.1 completed; JSON and zip archive parsers.

## Tasks

- [ ] **T-AUTH-164:** Implement 1Password 1PUX export parser extracting item TOTP URIs, account labels, and tags.
- [ ] **T-AUTH-165:** Implement Bitwarden JSON and CSV export parser with custom field TOTP detection.
- [ ] **T-AUTH-166:** Implement KeePassXC CSV and XML export parser with custom attribute mapping.
- [ ] **T-AUTH-167:** Add CLI flags `--dry-run` and `--conflict-action (skip|overwrite|rename)` with test suite in `tests/test_migration_exporters.py`.

## Outputs

- Password manager export parser in `src/authy_local/migration.py`.
- Automated test suite `tests/test_migration_exporters.py`.

## Validation and TDD

- Export round-trip tests validating identical TOTP generation before and after migration.
- Clean conflict handling ensuring no unintentional overwrites of existing account items.
