# S-AUTH-20.1: Native Rust cryptographic engine (PyO3, SIMD HMAC, constant-time Base32)

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement the native Rust extension `crates/authy_local_rust` with PyO3 bindings providing SIMD-accelerated HMAC calculations, constant-time Base32 decoding, and compiler-barrier zeroization.

Non-goals: Hard dependency on a Rust toolchain for end users; pre-compiled wheels provided with pure-Python fallback.

## Entry Conditions and Dependencies

Dependencies: Phase 19 completed; Rust 1.75+ / Maturin build toolchain.

## Tasks

- [ ] **T-AUTH-200:** Initialize PyO3 crate `crates/authy_local_rust` with Cargo manifest and build configuration.
- [ ] **T-AUTH-201:** Implement SIMD-vectorized HMAC-SHA1/SHA256 calculation routines.
- [ ] **T-AUTH-202:** Implement constant-time Base32 decoding preventing side-channel cache attacks.
- [ ] **T-AUTH-203:** Build automated parity and memory leak test suite in `tests/test_accelerator_crypto.py`.

## Outputs

- Native Rust crate `crates/authy_local_rust/`.
- Automated test suite `tests/test_accelerator_crypto.py`.

## Validation and TDD

- Parity tests verifying byte-identical outputs between Rust and Python implementations across 10,000 random seeds.
- Benchmark demonstrating >= 5x speedup in raw code calculation throughput.
