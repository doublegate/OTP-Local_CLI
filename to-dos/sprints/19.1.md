# S-AUTH-19.1: Hardware key credential lifecycle and touch-policy enforcement

Status: Planned; task IDs are allocated in [ROADMAP.md](../../ROADMAP.md).

## Goal and Scope

Implement YubiKey OATH credential lifecycle management in `src/authy_local/hardware_keys.py`, enabling direct slot configuration, configurable touch policies (`ALWAYS`, `CACHED`), and PIN administration.

Non-goals: Resetting FIDO2 keys without explicit, multi-step operator confirmation.

## Entry Conditions and Dependencies

Dependencies: Phase 18 completed; CTAP2 USB HID driver.

## Tasks

- [ ] **T-AUTH-190:** Implement YubiKey OATH application protocol client over CCID / HID.
- [ ] **T-AUTH-191:** Implement touch-policy enforcement (`ALWAYS` touch per code vs `CACHED` 15-second window).
- [ ] **T-AUTH-192:** Implement PIN verification, change PIN, and retry-counter inspection.
- [ ] **T-AUTH-193:** Build automated hardware key protocol test suite in `tests/test_hardware_keys.py`.

## Outputs

- Automated test suite `tests/test_hardware_keys.py`.
